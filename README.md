<h1 align="center">🐲 Pokedex Habit Tracker</h1>

📖 Overview

A full-stack gamified habit tracker that leverages the Pokémon theme to encourage personal growth. Built with a robust Node/Express backend and a responsive Vanilla JS frontend, this application provides a secure and engaging environment for users to manage their daily routines.

🔗 Live Link: https://pokedex-orcin-eight.vercel.app/

🚀 Key Features

🔐 Secure Auth: JWT-based user authentication and Bcrypt password hashing.

📋 Habit Management: Complete CRUD functionality to track, update, and delete daily goals.

⚡ Real-time Interaction: Dynamic frontend updates without page refreshes.

🎨 Pokedex UI: Custom CSS-designed interface themed around the Pokémon universe.

🌐 Cloud Native: Fully deployed on Vercel with MongoDB Atlas cloud integration.

🛠️ Technical Stack

Frontend

HTML5, CSS3, JavaScript (ES6+)

Backend

Node.js, Express.js

Database

MongoDB Atlas, Mongoose ODM

Auth

JSON Web Tokens (JWT)

Hosting

Vercel
